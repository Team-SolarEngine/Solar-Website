The following is a compiled list of changes added to or progress on currently in the work updates (Yes the roadmap will be updated at some point for 1.0.0)

## Solar Engine (Psych Fork Archive) 0.6.2 | ~50% done

- Moved the ClientPrefs to data like with psych 0.7.3, and added setPref and getPref as shortcut functions for this purpose
- Moved from a bool 'universe' variable to a string 'solar' for lua scripts to check the current solar variable.
- The Solar Icon Bop style now properly affects the scale by disabling the builtin scale bop while the icon bop option is enabled.
- Dark mode now no longer makes text unreadeable in the dialogue text substate/editor.
- The fps display now has multiple modes "Hide": Self-explanatory, "Simple": Normal FPS + Memory, "Extended": Provides additional stats, and can track variables, "Fancy": A stylized version inbetween "Simple" and "Extended".
