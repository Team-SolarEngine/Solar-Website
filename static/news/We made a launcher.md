# We made a launcher! Again.
It's stable, faster, and actually isn't shit.

## What do you mean "Again"?
Yeah, we made another one. The first one lasted only a few months, then we dropped it because it was too slow and unstable. Wanna know the framework? Literally fucking Haxeflixel. So we quickly dropped the idea of having a launcher. Then, a year went by, I thought of making a launcher again. The last launcher was only authored by [VideoBot](https://video-bot.netlify.app), and back then, we weren't really good programmers, designers, and we really did NOT know what we were doing. If you want the old lanucher (which is NOT reccomended), [here's the link](https://github.com/Team-SolarEngine/UELauncher-Archive)!

## What's improved?
Everything. Ever since I left the Solar Engine team, I started making my own apps, and started learning more things. What's the perk? I made the launcher better and faster. Better UI, better performance, and better everything.

## Tech stack?
The tech stack is not that complicated. It's only the following;
- [Tauri](https://tauri.app/) — Cross-platform framework & backend
- [Svelte](https://svelte.dev/) — Frontend framework
- [BeerCSS](https://beercss.com/) — UI framework

### Why Tauri?
Because I wanted to keep it lightweight, and stable to the point that we don't have bugs on the backend side! Sure, we could've used Electron, but that's heavy.

### Why Svelte?
I don't like React. Mainly because of it's Virutal DOM. Too much overhead, and I prefer to have more control over my code. That's why I chose Svelte. Svelte is a better choice, and uses a compiler. No overhead, and better performance. Sure, we could've used SolidJS, but Svelte is better for my use case.

### Why BeerCSS?
Because I like Material Design. And makes development for the Frontend easy because I don't have to think for the style of UI components.
